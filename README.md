# 金沢 旅のしおり

2泊3日の金沢旅行(2人)用の「旅のしおり」Webアプリです。
HTML / CSS / JavaScript だけで動く静的サイトで、ビルドは不要です。タブレットで使いやすいように作っていて、スマホやPCでも使えます。

- **編集する人**: アプリで行程・交通・宿・持ち物・お土産を入力します。
- **見るだけの人**: アプリが出力したしおり(PDF・スマホ用画像)を受け取って見ます。

## できること

| タブ | 内容 |
|---|---|
| 行程 | 3日分の予定。開始日を入れると日付が自動で入る。時刻・タイトル・場所・メモ・地図URL・種別(移動/観光/食事/宿泊/買い物)。追加・編集・削除・▲▼で並べ替え・時刻順に並べる。お土産の購入タイミングに選んだ予定には 🎁 品物名(購入場所) を表示 |
| 交通 | 区間・日時・列車名・号車座席・金額・乗車方法・手配済みチェック。合計金額を自動計算 |
| 宿・食事 | 宿(宿名・住所・IN/OUT・電話・地図)と予約した店(店名・日時・人数・電話・地図・メモ) |
| 持ち物 | 共通/自分/妻 の3区分のチェックリスト。追加・削除(元に戻す付き)。最初から定番の持ち物入り |
| お土産 | 相手・品物・購入場所・購入タイミング・予算・実額・購入済み・写真1枚・商品URL・メモ。「自分たち用」区分あり。合計予算・合計実額・残額を自動計算。**しおりには載りません** |
| しおり | A4縦プレビュー、PDF保存(印刷)、スマホ用PNG(日ごと分割 / 1枚にまとめる) |

## 使い方(すぐ試す)

1. `index.html` をブラウザで開きます(ダブルクリックでOK)。
2. 右上の「⚙ データ」→「サンプルデータを読み込む(架空)」で、入力例を確認できます。
3. 試し終わったら、「⚙ データ」→「すべてのデータを消す」で空の状態に戻してから、本番のデータを入力してください。

> スマホ用画像を作るときは、インターネット接続が必要です(ライブラリ html2canvas をCDNから読み込むため)。それ以外の機能はオフラインでも動きます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作ります(例: `kanazawa-shiori`)。
   - **Private リポジトリでも、GitHub Pages で公開したサイト自体は誰でも見られます**(無料プランでは Private リポジトリで Pages を使えない場合もあります)。サイトに個人情報は入っていません。個人情報は各端末のブラウザ内にだけ保存されます。
2. このフォルダの中身を push します。
   ```bash
   cd kanazawa-shiori
   git remote add origin https://github.com/<ユーザー名>/kanazawa-shiori.git
   git push -u origin main
   ```
3. GitHub のリポジトリ画面で **Settings → Pages** を開きます。
4. **Build and deployment** の Source で「Deploy from a branch」を選び、Branch を `main`、フォルダを `/ (root)` にして **Save** を押します。
5. 1〜2分待つと、`https://<ユーザー名>.github.io/kanazawa-shiori/` で開けるようになります。
6. タブレットやスマホでそのURLを開き、共有メニューの「ホーム画面に追加」をしておくと、アプリのように起動できます。

`.nojekyll` を置いてあるので、GitHub側でJekyllの変換は行われません。

## データの保存とバックアップ

- 入力したデータは、**その端末のそのブラウザの中(localStorage)だけ**に保存されます。サーバーには送られません。
- 端末やブラウザが変わるとデータは引き継がれません。下の手順で移してください。

### バックアップ / 別の端末へ移す

1. 元の端末で「⚙ データ」→「📤 データを書き出す(JSON)」を押すと、`kanazawa-shiori-日付-時刻.json` が保存されます。
2. そのファイルを別の端末へ送ります(AirDrop、メール、クラウドドライブなど)。
3. 別の端末でしおりを開き、「⚙ データ」→「📥 データを読み込む(JSON)」でファイルを選ぶと、データが**置き換わります**。

### 注意

- **iPhone / iPad の Safari** は、7日間ほど開かなかったサイトのデータを自動で消すことがあります。対策として、
  - 「ホーム画面に追加」して使う
  - 編集したら、こまめに JSON を書き出しておく
- ブラウザの「履歴とWebサイトデータを消去」やプライベートモードでは、データが消えたり保存されなかったりします。
- お土産の写真は自動で縮小しますが、枚数が多いと容量の上限(約5MB)に近づきます。使用量は「⚙ データ」で確認できます。
- **書き出したJSONには宿名などの個人情報が入っています。リポジトリにコミットしないでください。**(`.gitignore` で `*.json` を除外しています)

## しおりの出力

「しおり」タブで、出力する項目(表紙・行程・交通・宿泊/食事・持ち物)を選べます。お土産は常に出力の対象外です。

### PDF

- **PC(Chrome / Edge)**: 「🖨 PDFで保存・印刷」を押し、送信先で「PDFに保存」を選びます。用紙は A4・縦です。「背景のグラフィック」をオンにすると、色付きの部分もきれいに出ます。
- **iPad / iPhone**: 「🖨 PDFで保存・印刷」を押し、プリント画面の共有ボタンから「ファイルに保存」を選びます(またはプレビューを2本指で広げます)。
- ページの構成は、表紙 → 1日目 → 2日目 → 3日目 → 交通・宿・食事 → 持ち物 で、それぞれ新しいページから始まります。予定の途中でページが切れないようにしてあります。

### スマホ用画像(PNG)

- 「日ごとに分割」: 表紙 / 1日目 / 2日目 / 3日目 / 交通・宿・食事 / 持ち物 を別々の画像にします(おすすめ)。
- 「1枚にまとめる」: すべてを1枚の縦長画像にします。
- 作成後の「共有」で、写真アプリやLINEへ直接送れます(対応ブラウザのみ)。「保存」を押すとダウンロードされます。
